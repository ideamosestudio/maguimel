Funcionalidad para el trabajo real.

El uniforme profesional tiene que acompañar la tarea, ordenar la imagen y hacer sentir parte al equipo.

Desarrollamos prendas para industria, logística, salud, comercio y servicios. Combinamos tipologías, textiles, recortes, bolsillos y elementos de visibilidad según las necesidades de cada actividad.
